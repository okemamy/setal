# Changelog

## 1.0.1 — 2026-11-08

- Universal binary: runs on Intel Macs as well as Apple Silicon.
- Signed with a Developer ID and notarized by Apple: opens without a warning.
- Copyright: OKEMAMY.
- Homebrew size is read reliably; pnpm no longer overstates the gain.

## 1.0.0 — 2026-11-08

First public release.

- System Data tab: Docker (Docker Desktop, OrbStack, Colima), Xcode and
  simulators, Android and Flutter, package managers, outdated IDE versions,
  Electron and Chrome caches, iOS updates and backups, installers, caches,
  logs, Time Machine snapshots, Trash.
- Projects tab: finds `node_modules`, `build`, `Pods`, `target`… next to
  their ecosystem file; preselects inactive projects.
- Risk levels, confirmation for data loss, path guard, Trash for user files.
- Full Disk Access detection.
- 14 languages: English, French, Spanish, Portuguese, German, Italian,
  Dutch, Russian, Turkish, Arabic, Japanese, Korean, Simplified and
  Traditional Chinese.
- Donation link (PayPal) in the app menu, the info popover and after a
  successful cleanup.
